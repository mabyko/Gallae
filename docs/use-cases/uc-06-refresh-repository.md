# UC-06 · 현재 상태 새로고침

> 우선순위: P0

| 항목 | 내용 |
| --- | --- |
| 사용자 목표 | 터미널이나 다른 앱에서 바뀐 Git 상태를 다시 읽는다. |
| 시작 조건 | Repository Workspace가 열려 있다. |
| 진입점 | 앱 실행·복원·활성화 시 자동 새로고침, 사용자의 Refresh 명령 |
| 완료 상태 | 하나의 일관된 최신 상태가 화면에 반영된다. |

## 정상 흐름

1. Gallae가 현재 화면을 막지 않고 새 상태를 읽는다.
2. 읽기가 끝나면 Repository, 브랜치, 파일 목록과 선택한 diff를 함께 갱신한다.
3. 선택한 파일이 남아 있으면 선택을 유지한다.

## 대안 흐름

- 선택한 파일이 사라졌다면 예측 가능한 기본 항목으로 이동하거나 선택 없음 상태로 둔다.
- 읽기에 실패하면 마지막 성공 상태를 최신인 것처럼 표시하지 않는다.
- 실패 시점, 원인과 다시 시도 명령을 함께 표시한다.
- Repository 자체가 사라졌다면 Repository Library로 돌아갈 수 있게 한다.
- 이전 새로고침이 늦게 끝나더라도 더 최근에 시작한 결과를 덮어쓰지 않는다.

## 완료 확인

- 새로고침은 파일 선택과 창 조작을 막지 않는다.
- 한 번의 새로고침 결과는 Repository, 브랜치, 파일과 diff 사이에서 서로 어긋나지 않는다.
- 실패 뒤 다시 시도할 경로가 같은 화면에 남는다.
- 새로고침이 취소되면 오류로 표시하지 않는다.
